## 清理边界

当前发行目录包含 43 道独立算法练习、65 道独立深度学习练习及通用示例。专用来源的采集、转换、原始快照、导入说明与旧归档卷宗已移除。保留通用 JSON 导入。已有数据库的个人学习记录与题目不做破坏性删除，Git 历史不重写。测试截图中的总数来自现有本地数据库，不代表新安装的发行数量。

本地索引目录不属于交付代码；验收期间停止索引后台进程以避免文件快照竞争。删除的旧归档文档已在 Git 索引中登记，保留当前规格和本报告作为交付说明。

收藏与错题导航的查询参数及筛选状态同步已通过浏览器检查；记录、进度和后台的可见文字字号检查通过（不低于12px）。
