# Outcome
将 CodeAce 的题库、做题工作台和主要辅助页面改为一致的深色紧凑界面，移除装饰小字、第三方参考平台关联和专用导入链路。用户已明确委托先写规格后直接实施，不等待逐步确认。

# Scope
题库采用紧凑侧栏、分类胶囊、知识点筛选、交替底色题目行和真实进度；做题页采用全宽双栏，题面、代码、输入输出独立面板。辅助页面沿用统一设计。删除指定参考平台的名称、链接、快照、专用采集/转换脚本和导入说明；保留独立练习及通用 JSON 导入。参考页仅为视觉参考，已通过指定浏览器配置读取列表及一个详情页，两次导航完成观察。

## 目录结构
### 修改
- app/layouts/、app/pages/、app/assets/css/、app/components/CodeEditor.vue — 布局、视觉与可读性。
- scripts/、database/、tests/、package.json、README.md — 去除专用来源依赖，维护离线目录和验证。
- docs/ — 清理过时来源说明并记录现行规格。
### 删除
- 专用来源快照、采集和转换入口 — 移除平台依赖与导入指南。

# Non-goals
不复制参考站商标、广告、会员、竞赛、社区或企业数据。不重写 Git 历史、不删除个人草稿、收藏、笔记与提交。不做公网部署。

# Acceptance examples
- A1：题库在桌面和移动端显示深色导航、分类、搜索、筛选、真实数量与题目行；筛选、分页和返回上下文正常。
- A2：做题页为全宽双栏工作台，窄屏可使用；题面、题解、记录、笔记、语言模式、草稿、运行提交和结果可用。
- A3：登录、进度、记录与后台沿用统一颜色及可读字号；无装饰标语、英文副标题或小字注释。
- A4：当前仓库文件及路径不含指定参考平台标识，专用导入脚本、快照和说明已移除；独立题库可离线构建，通用导入保留。
- A5：类型检查、单元测试、构建与主要页面浏览器验收通过；提供本地截图及检查记录。

# Constraints and invariants
沿用 Nuxt、Vue 和现有执行器。页面正文 14–16px，功能标签至少 12px。保留真实数据，不虚构通过率或打卡。参考访问低频且不采集题库。源内容移除不以改名冒充原创，已存在的个人学习记录保留。
