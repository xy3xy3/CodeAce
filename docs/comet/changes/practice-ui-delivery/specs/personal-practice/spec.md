# CodeAce 个人刷题完整规格

## 边界
面向单用户个人使用，采用独立品牌的深色刷题界面。中文 Nuxt 应用使用 pnpm 与 shadcn-vue，pgvector PostgreSQL 18 持久化。无公开注册、竞赛、支付会员、排行榜、社区、实时协作、AI 功能、自动间隔复习或公网部署。保留在当前 master 工作区，不推送 Git。

## 工程与部署
Compose 提供 pgvector 数据库、独立执行器及可部署应用配置；本地开发允许 pnpm 启动 Nuxt。通过迁移创建 vector 扩展和业务表。数据库端口、凭证、数据卷和管理员初始化均使用环境变量；.env.example 不含真实凭证。README 解释初始化、启动、迁移、备份、沙箱构建和测试。

## 题库
题库首页具有分类导航、可选个人题单/收藏、搜索、难度、标签、完成状态筛选和分页。Hot 100 与 Hot100 归一化。显示真实个人完成数量、总可刷数量、难度、标签和通过状态；来源统计不得冒充本地个人统计。详情返回后恢复筛选与页码。

## 详情
左侧切换题面、题解、提交记录；右侧为编辑器和输入输出面板，布局可调并支持窄屏。安全渲染 Markdown、数学公式、代码、样例解释、输入输出说明、数据范围、提示、运行限制。支持题单内前后题及相似题链接。题解可导入开放正文或由本人管理，无正文显示暂无题解。不可读商业题解不导入假正文。保存个人 Markdown 笔记和收藏；错题列表定位最近未通过且尚未解决题目。

## 执行
语言 ID 为 python3、cpp17。Hot100/深度学习只允许 python3，通用题可配置 python3/cpp17。Python 环境预装 NumPy/PyTorch CPU，模板可选择其一，均归属 Python3。每题按已配置的模板、输入规格和用例声明 function/acm 模式；至少有函数和 ACM 真实示例。选择模式与语言时加载对应模板并分别保存草稿，切换不能覆盖其他草稿。

ACM 将纯文本作为 stdin，程序 stdout 与标准答案按题目比较规则比较；C++17 先独立编译并识别编译错误。函数模式支持普通函数、Solution 方法与设计类/原地修改题的题目专用 harness、链表和树的构造/序列化；用户无需编写平台 main。参数输入和输出规则在 UI 清楚展示。深度学习可运行来源 input_by_lang 的 torch/numpy 调用代码，仅限沙箱内。JSON、文本 tokens、无序 tokens/结构及浮点容差比较保持来源语义，维度/长度不同不得因数值巧合通过，NaN/Inf 与容差有明确规则。

运行可选择样例和自定义输入；自定义输入无标准答案时只展示输出，不声称 AC。正式提交使用题目版本的正式用例，保存源代码快照、语言、模式、判题状态、用时、内存、通过数与诊断。执行结果由执行器基于进程和比较器产生，用户输出不能伪造服务回包。区分排队、执行中、AC/WA/CE/RE/TLE/MLE、输出超限和系统错误。执行器不可用明确失败，不产生虚假的通过记录。限制并发和队列长度，重启后中断任务可恢复或明确标记中断。

## 记录与个人学习
提供全局及单题提交记录，按题目、结果、语言筛选并查看代码和诊断；记录对应提交时题目/用例版本。样例运行不更新完成进度；至少一次正式 AC 后保持已通过状态。保存草稿、笔记、收藏、最后练习时间、按日提交/通过统计和错题状态。浏览器刷新和服务重启后仍可访问。

## 认证与后台
仅一个管理员账户，通过初始化命令或环境变量配置初始身份，密码使用安全哈希，登录使用安全 HttpOnly cookie 会话，退出失效；登录有请求频率限制，写请求防 CSRF/跨源调用。所有个人数据、管理与执行 API 均检查身份；机器导入支持独立密钥鉴权。无公开注册。

后台可新建、编辑、删除或归档分类和题目；维护标题、正文、来源、标签、难度、题解、语言、模式、模板、参数、harness、样例/隐藏用例、比较方式/容差、执行限制和发布状态。发布前校验完整性。缺少题面或可执行契约的来源条目只作为待补齐草稿，不能在公开刷题列表宣称可判题。修改题目不篡改历史提交快照。

## 离线题库与导入
发行题库由独立练习组成，离线生成且重复运行不覆盖手工修改和个人学习记录。移除第三方平台专用快照、采集器、转换器及导入说明，不通过更换来源名称保留原平台正文。通用鉴权 JSON 导入支持 dry-run、逐题校验和幂等来源键。

## 沙箱
独立 Docker 执行器负责隔离容器调度，Web 服务通过受保护私有接口提交任务，不能直接访问 Docker socket。非 root 执行，禁网、drop capabilities、no-new-privileges、只读根文件系统、有限临时目录，禁止挂载宿主敏感路径。为编译与执行设置 CPU、墙钟、内存、进程、输出及磁盘限制，超限终止进程/容器并清理。每个测试用例隔离，不向用户程序提供预期输出和其他隐藏用例。比较器在受控执行器内消费有限输出，可信状态通过控制通道生成。仅执行器控制面持有 Docker 调度权限，不能把 socket 暴露给用户容器。

## 界面规格
默认深色背景 #141414、面板 #242424、工具栏 #303030，正文浅灰，绿色执行操作，橙色中等难度。顶栏 60px，题库侧栏约 200px；分类和搜索采用胶囊/圆角控件，题目行紧凑交替底色，标签和统计为真实数据。保留 CodeAce 独立品牌，不显示广告或会员入口。
做题页隐藏全局侧栏，顶部保留返回、前后题、运行、提交，左右为题面与代码；代码下方是输入/结果面板。窄屏上下排列且不裁切操作。辅助页面使用相同设计令牌。删除宣传语、装饰英文和说明小字，必要错误、状态、字段标签和题目正文正常显示。

## 验收
### Scenario: 题库浏览
Acceptance: A1
在桌面和移动端检查分类、搜索、状态、难度、标签、分页与返回上下文。
### Scenario: 编程工作台
Acceptance: A2
打开题目，切换面板、语言和模式，保存笔记草稿，运行与提交后展示真实结果。
### Scenario: 统一界面
Acceptance: A3
检查登录、记录、进度、后台与主要页面，无装饰小字并有清晰状态和表单。
### Scenario: 独立发行
Acceptance: A4
检查仓库文本与路径、离线构建和通用导入，指定平台信息与专用导入依赖均不存在。
### Scenario: 验证
Acceptance: A5
类型检查、单元测试、构建、浏览器交互与桌面/窄屏截图确认。
